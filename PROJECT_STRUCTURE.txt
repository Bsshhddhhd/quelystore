🚀 خطوات الإعداد والإطلاق
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. إعداد MongoDB:
   ✓ أنشئ حساب على https://mongodb.com/cloud/atlas
   ✓ أنشئ Cluster
   ✓ احصل على Connection String ونسخه

2. إعداد Discord Webhook:
   ✓ افتح سيرفر Discord
   ✓ Settings > Integrations > Webhooks
   ✓ Create Webhook واحصل على الرابط

3. تحديث .env.local:
   ✓ ضع MONGODB_URI
   ✓ ضع DISCORD_WEBHOOK_URL
   ✓ ضع مفاتيح Stripe/KPAY

4. تشغيل المتجر:
   ✓ npm run dev
   ✓ افتح http://localhost:8080
   ✓ استمتع! 🎉

Frontend:
  - Next.js 13 - Web Framework
  - React 18 - UI Library
  - TypeScript - Language
  - Tailwind CSS - Styling
  - PostCSS - CSS Processing

Backend:
  - Next.js API Routes - Server
  - Mongoose - Database ORM
  - MongoDB - NoSQL Database
  - Stripe - Payment Processing
  - Axios - HTTP Client

Security:
  - bcryptjs - Password Hashing
  - jsonwebtoken - JWT Auth
  - dotenv - Environment Variables

Integration:
  - Discord.js Webhooks - Discord API
  - Stripe API - Card Payments
  - KPAY API - Kuwait Payments
